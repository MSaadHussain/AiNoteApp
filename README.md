# 📝 NoteNest AI

> An AI-powered note-taking assistant built to help students capture, organize, and understand their lectures effortlessly.

## 🚀 Overview

**NoteNest AI** is an intelligent student productivity platform designed to transform the way students take and manage notes.

Built during a hackathon by a team of students, NoteNest combines AI-powered transcription, organization, and question-answering features to create a smarter learning experience.

Instead of manually writing, organizing, and searching through notes, students can focus on learning while AI handles the heavy lifting.

---

## ✨ Features

### 🎙️ AI Lecture Recording
- Record lectures and convert speech into structured notes
- Save important information automatically
- Reduce the need for manual note-taking

### 📚 Smart Note Organization
- Automatically organize notes into subjects and categories
- Create digital notebooks for different courses
- Easily search and access previous lectures

### 🤖 AI Question Assistant
- Ask questions directly from your notes
- Get quick explanations and summaries
- Understand difficult concepts faster

### 🧠 Intelligent Summaries
- Generate concise summaries from lengthy lectures
- Highlight key points and important information

## ⚙️ Installation & Setup

### Clone the repository

```bash
https://github.com/MSaadHussain/AiNoteApp.git
```

### Navigate into the project

```bash
cd notenest-ai
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```
